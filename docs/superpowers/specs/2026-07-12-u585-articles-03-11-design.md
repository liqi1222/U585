## 两阶段架构

### 阶段 A（少改 `.ioc`）

| 篇 | 重点 | 依赖 |
|----|------|------|
| 03 | 回填已验证 LED/按键/VCP 结论 | 现有 GPIO NS |
| 04 | SWO/ITM + VCP 双通道日志；可选 Fault（宏开关） | 现有 |
| 05 | 时钟快照经 VCP 打印 + `g_u585_clock_snapshot` | HAL RCC |
| 06 | 读 PWR 电源模式/电压档 + 标记需电流表项 | PWR 寄存器 |
| 07 | Sleep 短时进入钩子 + LED 心跳；Stop/Standby 标待补测 | WFI 安全子集 |
| 09 | 先完善边沿检测；EXTI 在阶段 B 随 NVIC/GPIO 归属落地 | GPIO |

### 阶段 B（集中迁 NonSecure）

迁移清单（最小集）：

1. **USART1**（PA9/PA10）→ NonSecure：GTZC `USART1` 非安全；NS 侧直接 `HAL_UART`；`u585_log` 可改为本地 UART（保留 NSC 回退可选）。
2. **RTC** → NonSecure：供 08 唤醒/备份域实验。
3. **TIM**（选板载可用通道，优先能驱动 LED 或可观测引脚）→ NonSecure：供 10 PWM/输入捕获。
4. **PC13 EXTI** → NonSecure NVIC：供 09 外部中断。

Secure 仍负责：启动、时钟树配置、GTZC 初始分区、未迁移外设。

## 风险

- 改 GTZC/USART 归属可能导致 VCP 短暂失效：迁移后先验证 `exp11`/`exp03` 日志。
- 低功耗 Stop/Standby 易丢调试连接：07 默认只做 Sleep；更深模式需显式宏且标待补测。
- CubeMX 再生可能覆盖手改：`.ioc` 与 USER CODE / App 层分离，关键归属改完后记录在 `U585_EXPERIMENTS.md`。
